# Support

## Before opening an issue

1. Update to the latest version from the
   [Chrome Web Store](https://chrome.google.com/webstore/detail/show-my-ip-addresses-exte/opljiobgnagdjikipnagigiacllolpaj).
2. Check the [existing issues](https://github.com/DoctorLai/what-is-my-ip/issues)
   for the same problem.
3. Reload the extension from `chrome://extensions` and try again.

## Bugs and questions

Use the repository's
[bug report form](https://github.com/DoctorLai/what-is-my-ip/issues/new?template=bug_report.md)
for reproducible extension problems. Include the extension version, Chrome or
Chromium version, operating system, installation source, and clear reproduction
steps.

The popup's **Show API Log** option can help diagnose lookup failures. Remove or
mask public and local IP addresses before posting logs or screenshots.

General help is provided on a best-effort basis. There is no guaranteed response
time or service-level agreement.

## Feature requests

Use the
[feature request form](https://github.com/DoctorLai/what-is-my-ip/issues/new?template=feature_request.md)
and describe the user problem as well as the proposed behavior.

## Security and privacy

Do not report security vulnerabilities in a public issue. Follow the private
reporting process in [SECURITY.md](SECURITY.md). For details about network
requests, browser storage, and data handling, read [PRIVACY.md](PRIVACY.md).

## Other services

The linked web tool and third-party IP lookup services are separate from the
extension. Their availability is not controlled by this repository.
