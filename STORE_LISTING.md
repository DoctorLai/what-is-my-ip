# Chrome Web Store listing

Use the following copy for the English (United States) Store listing.

## Short description

Shows your external and local IP addresses in one click.

## Detailed description

Open the extension popup to see the public address used by your internet
connection and any addresses detected on your local network.

Each result is labelled as IPv4 or IPv6 and public or private. Refresh updates
the results without reopening the popup, and the copy controls let you copy any
address. The extension can retain up to 50 previously seen public addresses so
you can notice changes. You can clear this history at any time.

Public-address lookups use two network services for redundancy. Local detection
runs in the browser through WebRTC. The storage permission is used only to
retain history, and the extension includes no analytics.
